New to Programming!

In this project I followed the instructions to complete the "Project Recipes" in the Odin Project Foundations Course.

To completed this project, the Following Components were used:

* Standard html boilerplates 
* Anchor tags to navigate relative links
* img tags to insert images
* h tags for headers
* p tags for paragraphs and text
* ul tags to display recipe ingredients as an unordered list
* ol tags to display steps to making the recipe
